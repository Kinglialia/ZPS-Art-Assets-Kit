# v0.3.1 — review fixes, 2026-11-05

This revision retains the seven ZPS display names and technical identifiers. It has not been installed into the user's live skills roots.

1. Added a manifest alias map for unprefixed names and former ZPS names, including zps-art-library-manager. Preview/install/verify refuse duplicates across the target, ~/.agents/skills and CODEX_HOME/skills. Same-name updates at the selected target remain supported. INSTALL.md provides an explicit archive-and-restore migration procedure; no automatic folder deletion or library movement.
2. Moved upstream approval, installation and Benchmark V2 history outside runtime into release-notes. Removed historical approval/deployment fields from current skill metadata and removed runtime routes to release gates. Validation remains pending; no production certification or artistic improvement is claimed.
3. Removed repeated history and handoff boilerplate. Moved formal acceptance and revision tracking to Artistic Critique's conditional reference; quick reviews no longer require issue IDs. Seven entrypoints decreased from 5,965 to 5,465 whitespace-delimited words (about 8.4%). Independent-use visual evidence limits remain intact.
4. Replaced owner-specific Drive IDs and old project paths with an optional project-local art-library.json schema or a location supplied in the task. No data synchronization or project config writes are performed by the installer.

Checks: payload hashes/sizes, Markdown links, frontmatter identifiers, YAML parsing with Ruby Psych, preview/cancel no writes, isolated install/verify, idempotence, upgrade backup and restore, refusal to overwrite later edits, unrelated-file preservation, every alias in each root, duplicate new names across roots, corrupt/unlisted payload rejection and destination symlink rejection. Limits: this is a self-review and technical test pass, not a behavioral benchmark, independent art review or Codex UI-discovery test. Original benchmark materials remain unavailable. The ZIP contains no reference image library.
