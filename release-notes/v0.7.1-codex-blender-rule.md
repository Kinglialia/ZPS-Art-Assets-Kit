# v0.7.1 — Rule Codex cho Blender, chuẩn hóa lệnh Blender

Base: v0.7.0.

## Vì sao

Trong sandbox của Codex trên macOS, Blender crash ngay lúc khởi động (sandbox chặn bước dò GPU Metal). Mọi bước kiểm model của Texture và toàn bộ tool 3D cần Blender. Anh chọn phương án C: chỉ cho phép đúng các script của kit chạy Blender ngoài sandbox; mọi lệnh khác vẫn trong sandbox hoặc phải hỏi.

## Thay đổi

- **`installer/codex_rules.py` (bản Codex, mới):** tạo file `~/.codex/rules/zps-art-assets-kit.rules`. Rule cho phép, ngoài sandbox và không hỏi, đúng ba dạng lệnh:
  - `<Blender> -b --python <script đã cài của kit> -- …`
  - `<Blender> -b --python-exit-code 1 --python <script đã cài của kit> -- …`
  - `<Python của venv 3D> <sweep.py | apply_edit.py | preflight.py> …` (ba script này tự mở Blender).
  Script tự tìm Blender và thư mục kit, liệt kê 49 script của kit, tự kiểm rule bằng `codex execpolicy check` (lệnh của kit được phép; `--python-expr`, script lạ, `python -c` không được phép). Mặc định chỉ xem trước; `--write` mới ghi. Không ghi đè file rule không do kit tạo.
- **Chuẩn hóa lệnh Blender trong tài liệu:** mọi lệnh Blender dùng đường dẫn tuyệt đối viết thẳng (không qua `$BLENDER`, `$ART_TOOLS`), vì rule so khớp đúng chữ của lệnh. Sửa trong `scripts/README.md`, `pipeline.md`, `optimize.md`, `self_build.md`.
- **Sửa lỗi cũ:** README hướng dẫn `python3 render_model.py` / `inspect_model.py`, nhưng `python3` của máy không có `bpy`. Nay hướng dẫn chạy qua `Blender -b --python … -- …`.
- Adapter Codex, ghi chú cài đặt Codex, `AGENTS.md`, `docs/EDITIONS.md` mô tả rule và dạng lệnh bắt buộc.
- `tests/test_codex_rules.py` (mới); `build.py` chạy test này cho bản Codex và chép file trong `editions/<bản>/installer/` vào gói.

## Kiểm

- `python3 build.py --edition all`: hai bản qua mọi kiểm và test (svg_render, anim_preview, codex_rules).
- Cài thử bản Codex vào HOME tạm, chạy `codex_rules.py` xem trước và `--write`: rule đúng, tự kiểm qua.

## Chưa kiểm

- Rule chưa được thử trong một phiên Codex thật có model (Codex chỉ nạp rule khi khởi động phiên).
- Đường dẫn trong rule là đường dẫn thật đã resolve; nếu thư mục skill nằm sau symlink, agent phải dùng đúng đường dẫn đó.
