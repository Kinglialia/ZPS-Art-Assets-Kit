# v0.7.0 — Một nguồn, hai bản (Codex và Claude Code), toàn bộ tiếng Anh

Base: v0.5.6.

## Vì sao

- Kit v0.5.6 viết cho Codex nhưng được cài cả vào Claude Code. Kiểm trong sandbox thật của Codex cho thấy vài chỗ không chạy đúng (Blender, độ dài description).
- Cần một cách để agent mới tự build đúng hai bản khi được yêu cầu.

## Thay đổi chính

**Cấu trúc repo**
- `src/`: nguồn duy nhất của skill, tên skill không có đuôi (`zps-asset-2d`).
- `editions/codex`, `editions/claude`: phần khác nhau giữa hai bản (adapter, cấu hình cài, ghi chú, `openai.yaml` cho Codex).
- `package/`: INSTALL, TOOLS, CAPABILITIES, installer dạng mẫu.
- `build.py`: build hai bản, tạo manifest, chạy kiểm (tên, description ≤ 300 ký tự, link, placeholder, tên Codex lọt vào bản Claude) và test script, đóng ZIP vào `dist/`.
- `AGENTS.md` (và `CLAUDE.md` trỏ tới nó): luật sửa, build, release cho agent. `docs/EDITIONS.md`: bảng khác biệt giữa hai bản.

**Hai bản**
- Codex: skill `zps-<tên>-codex`, cài vào `~/.agents/skills`, có `agents/openai.yaml`; Art Learning chỉ chạy khi gọi tên.
- Claude Code: skill `zps-<tên>`, cài vào `~/.claude/skills`. Installer coi các tên `-codex` của bản Claude v0.5.6 là xung đột cần cất.
- Installer đọc thư mục cài, thư mục cần kiểm xung đột, tên app và chỗ backup từ `manifest.json`.

**Sửa cho Codex**
- Adapter Codex ghi rõ: Blender phải chạy ngoài sandbox (crash khi dò GPU Metal trên macOS), mạng tắt mặc định, thư mục skill chỉ đọc, `svg_render` cần resvg-py (Chrome dự phòng crash trong sandbox).
- 18 description viết lại bằng tiếng Anh, tối đa 300 ký tự (tổng 3.725 ký tự, trước là 9.204), mỗi cái 2–3 trigger tiếng Việt. Phần "không dùng cho…" chuyển xuống body.
- Mọi lệnh dùng `python3`; tool 3D dùng Python của venv 3D.
- Bỏ `zps-3d-artist/tools/install_global.sh` (script cài cũ chỉ dành cho Claude).

**Adapter Claude Code**
- Chọn công cụ gen ảnh: công cụ có trong phiên (ví dụ Gen3D `generate_image`), Codex CLI, hoặc API trả phí; không có thì giao brief và ghi rõ chưa làm bước ảnh.

**Tiếng Anh**
- 53 file nội dung tiếng Việt (body skill, reference, template, luật chung) được dịch sang tiếng Anh bởi subagent Sonnet theo bảng thuật ngữ chung, rồi soát lại cấu trúc (heading, bảng, list, link, code giữ nguyên) và soát nội dung.
- Skill trả lời user theo ngôn ngữ của user.

**Công cụ**
- `check_tools.py` kiểm glTF validator thật (không chỉ có Node) và kiểm rembg import được. TOOLS.md cài `rembg[cpu]`.

## Kiểm

- `python3 build.py --edition all`: cả hai bản qua mọi kiểm (tên khớp thư mục, description ≤ 300 ký tự, không link hỏng, không còn placeholder, không có tên Codex trong bản Claude) và test `svg_render`, `anim_preview`.
- Soát bản dịch bằng script: 53 file giữ nguyên heading, bảng, link, code, anchor và placeholder; không còn tiếng Việt trong nội dung skill (trừ trigger trong description và báo cáo `report.py` cố ý xuất tiếng Việt cho user). Khác biệt duy nhất: một số đoạn dài được tách thành gạch đầu dòng. Đọc soát nội dung các file luật chính và 2D Review, Surface.
- Phát hiện khi dịch: `tools/report.py` của 3D đọc dòng "KẾT LUẬN" của critic. Đã sửa để đọc cả "VERDICT" (mẫu mới) lẫn "KẾT LUẬN" (kết quả cũ); prompt critic ghi rõ giữ nhãn tiếng Anh.
- Cài thử vào HOME tạm: bản Codex và bản Claude cài mới đều `PASS`; nâng cấp Codex từ v0.5.6 lên v0.7.0 `PASS`.
- Cài thật bản Claude vào `~/.claude/skills` (18 thư mục `-codex` của v0.5.6 đã cất vào `~/.local/share/zps-art-assets-kit/archived/2026-11-06-claude-v0.5.6`); dựng lại venv 3D; `check_tools.py` báo đủ mọi công cụ, kể cả rembg.

## Chưa làm / chưa kiểm

- Chưa thử trong một phiên Codex thật với model (chỉ thử script trong `codex sandbox`).
- Cách cho phép lệnh Blender chạy ngoài sandbox qua rule của Codex chưa được kiểm cú pháp.
