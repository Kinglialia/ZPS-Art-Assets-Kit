# ZPS Art Assets Kit

Art skills for game production: concept, 2D assets and UI, textures, static 3D props, review, reference library and project learning. One source builds two editions: **Codex** and **Claude Code**.

- **Use the kit:** download the ZIP for your app from the GitHub release, then follow `INSTALL.md` and `TOOLS.md` inside it.
- **Change or build the kit:** read [AGENTS.md](AGENTS.md), then run `python3 build.py --edition all`.
- **Differences between the editions:** [docs/EDITIONS.md](docs/EDITIONS.md).
- **Change history:** [release-notes/](release-notes/).
